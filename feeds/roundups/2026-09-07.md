## 3. Data Engineering & Tooling

- **Orchestration consolidation:** Prefect announced (2026-07-13) it is **acquiring Dagster Labs** — both products continue independently for now, but this puts the two leading Airflow alternatives under one company. Relevant for any sports-analytics team standardizing a pipeline stack.
- **Airflow 3** has shipped three minor releases since its April 2025 debut, closing feature gaps (asset-centric scheduling, etc.) that Dagster/Prefect had used as differentiators.
- **dbt + Dagster:** Dagster's Software-Defined-Assets model keeps gaining adoption specifically for its native dbt integration (asset-level lineage, freshness tracking) versus Airflow's operator-based dbt triggering.
- **Apache Arrow:** latest dated release found is **25.0.1 (2026-08-10)**; no September release surfaced. Arrow's IPC/columnar format continues to run underneath pandas, Polars, DuckDB, Spark, and Snowflake — the "invisible standard" framing shows up repeatedly in recent commentary marking Arrow's ~10-year mark.
- **Polars:** no dated September release found this pass; general 2026 commentary continues to position Polars alongside DuckDB as the default fast-path for medium-data workloads that would previously default to pandas — directly relevant to sportsdataverse-scale play-by-play/tracking datasets.
