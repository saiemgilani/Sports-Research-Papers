## 3. Data Engineering & Tooling

- **Polars 2.0.0:** the [releases page](https://github.com/pola-rs/polars/releases) lists a 2.0.0 stable on 6 Oct. It enables out-of-core processing by default and adds a streaming sort. SQL window and QUALIFY semantics changed, and `Map` dtype and grouping-set support landed in rc.2. Secondary sources say `LazyFrame.collect()` now defaults to the streaming engine, so join, group_by and unpivot row order is no longer guaranteed. They also say to audit order-sensitive code and add `maintain_order=True`, and to pin `polars<2.0` until then. Only the GitHub page was a primary source, and I did not verify the engine-default and ordering claims against official notes.
- **Apache Arrow 26.0.0:** conflicting evidence. [The release page](https://arrow.apache.org/release/) fetch reported 26.0.0 dated 9 Oct 2026, but a web search showed 25.0.0 (10 Jul) as the newest listing with no 26.0.0 announcement. Treat 26.0.0 as unconfirmed.
- Nothing notable found on pipeline orchestration (Dagster, Airflow) or cloud data infrastructure this week.
