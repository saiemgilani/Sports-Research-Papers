## 3. Data Engineering & Tooling

- **Polars 2.0** (reported 2026-10-06): streaming becomes the default `collect()` engine, and row order is no longer guaranteed for some join/group_by/unpivot paths unless `maintain_order=True`. Reports count about 36 documented breaking changes. One streaming `select` row-reordering regression was reported fixed. Sources disagree on whether 2.0 is final or a release candidate, so check PyPI. [Release post](https://pola.rs/posts/release-polars-2/), [upgrade summary](https://www.kunalganglani.com/blog/polars-2-0-upgrade-guide). Action for sports pipelines: audit any code that relies on implicit row order, such as play sequencing after joins.
- **Apache Arrow 26.0.0** (about 10-08/09; 337 issues, 108 contributors): [release page](https://arrow.apache.org/release/26.0.0.html). **ADBC 25** shipped 10-26 ([upgrade guide](https://datalakehousehub.com/blog/adbc-25-upgrade-guide)).
