## 4. Where these ideas connect in the SportsDataverse community

Mapped from the papers to existing work in the saiemgilani / sportsdataverse repos (no changes were made there in this run — these are candidates for follow-up):

- **Who Blocks Whom** → NFL Big Data Bowl tracking in the nflverse ecosystem; complements line-play evaluation and sdv-py's `usage_box` / `defense_vs_position` analytics. A reproducible implementation on BDB data would fill a gap (the paper releases no code).
- **Hawkes credit attribution** → candidate method for possession-level credit in `sportsdataverse-py` soccer (ESPN/StatsBomb-style event data); pairs with `rolling_windows` / `metric_curves` surface.
- **Rugby Markov chain** → the same EP/WP state-table construction as `wexp` and `nfl/ep_wp.py`; a rugby/soccer extension of `wexp` baselines.
- **Polars 2.0.0 / PyArrow 26** → directly affects sportsdataverse-py (`polars>=1.0,<3`, `_fetch_release_parquet` via Arrow) and game-on-paper-app's `python/` processor; run the suite against both on the next dependency pass.
- **Reproducibility-companion format (risky tackle)** → worth borrowing for the Paper Index "oracle fixture" documentation in game-on-paper-app.
