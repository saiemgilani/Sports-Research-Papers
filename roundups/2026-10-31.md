## 4. Analysis and cross-links

- **Time-to-arrival (2610.36183)** is the strongest candidate to port. `sportsdataverse-py` now ships kloppy SPADL/xT
  and tracking-adjacent helpers; a TTA model would slot in beside them under `sportsdataverse.analytics`. The paper's
  data is PFF FC's public World Cup release — keep the data out of cloud sessions per the repo rules; the paper and
  its code are fine to cite.
- **Pose negative result (2610.38308)** is a reminder for the `game-on-paper-app` Paper Index work: added features
  moved held-out value less than the training objective. Same lesson as the repo's existing ranking note that
  "the control group and the null test are worth more than the model".
- **Mapping Academic Sports Analytics (2610.32354)**: its area taxonomy could seed tags for
  `paper-ranking-scores.csv` (currently only sport). Football/NFL is under-represented in this library
  (26 of 266) relative to basketball (85).
- **sportsdataverse-py 0.2.0b1** changes error semantics; downstream scrapers that relied on empty frames
  (`game-on-paper-app` processor, `*-data` pipelines) should test against the beta before 0.2.0 final.
