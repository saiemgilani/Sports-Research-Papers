## 2. Open-Source Packages & Ecosystem Updates

- **sportsdataverse-py `v0.2.0b1` (2026-10-26, beta; `pip install --pre`)** — first release since 0.1.4. 16 breaking changes: failed fetches now raise `AssetFetchError` / `NoDataError` / `ValueError` instead of returning empty frames; polars `>=2.0,<3` required; parser id columns are Int64; package reorganised (`basketball`, `providers`, `analytics`; old paths warn until 0.4.0). New sources: PFF Developer API, F1, EuroLeague, 24 international basketball + 12 European hockey families, kloppy soccer events with SPADL/xT, Polymarket, Kalshi. New MCP docs server (`sportsdataverse[mcp]`). Known issue: Python 3.10 stays on Pillow 12.3.0 with open advisories (use 3.11+). Feedback thread: sportsdataverse-py #1021. [Release](https://github.com/sportsdataverse/sportsdataverse-py/releases/tag/v0.2.0b1)
- **R packages (latest on CRAN, none newer than 5+ weeks):** nflfastR 6.0.0 (2026-09-18, *earlier*), baseballr 2.0.0 (08-26), hoopR 3.1.0 (08-25), fastRhockey 1.0.0 (08-25), cfbfastR 3.0.0 (08-24), wehoop 3.0.0 (08-24), nflreadr 1.5.1 (04-13). No R-package releases in the past 7 days.
- Implication for this library: the Big Data Bowl–based and PFF-charting–validated papers above (pass blocking) pair naturally with nflverse/`nflreadr` tracking-adjacent loaders and sdv-py's new `pff_api_*` surface.

## 3. Data Engineering & Tooling

- **Polars 2.1.0 (2026-10-25)** — first minor after 2.0.0 (10-06). Breaking: eager mode rejects string×number arithmetic. New: SQL (CREATE TABLE for Iceberg catalogs, recursive CTEs, ASOF joins, `generate_series`), Iceberg `sink_iceberg` overwrite/partition options and `pl.delete_iceberg`, encrypted Parquet, experimental GeoParquet. Perf: tighter out-of-core streaming sorts/group-bys/windows, faster Parquet decode and cloud CSV/NDJSON scans. [Notes](https://github.com/pola-rs/polars/releases/tag/py-2.1.0)
- **DuckDB 2.0.0 LTS "Cinnamon Teal" (2026-10-21)** with follow-up ["Gems of DuckDB 2.0.0"](https://duckdb.org/news/) (10-26); new parser announced in August; CLI "agent mode" post (10-09). 2.0.1 dev builds already nightly.
- **Apache Arrow / pyarrow 26.0.0 (PyPI 2026-10-09)** — release blog post not located; treat details as unverified.
- **Orchestration:** Apache Airflow 3.4.0b1 (10-13) and b2 (10-20) in beta; Dagster 1.13.26–1.13.27 (10-09, 10-26); dbt-core 2.0.0rc9 (10-14) alongside 1.12.6 — dbt 2.0 GA appears imminent; Prefect 3.9.x dev builds daily.
