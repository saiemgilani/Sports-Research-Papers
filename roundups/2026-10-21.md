## 3. Data Engineering & Tooling

- **Polars 2.0.0** (2026-10-06): out-of-core processing on by default (80% RAM / 64 GB disk
  budget), streaming sort, `struct.eval`, `pipe_with_dtype`, expanded SQL (ROLLUP/CUBE/GROUPING
  SETS, window functions), experimental `scan_lance`; breaking SQL decimal/window semantics,
  Parquet ENUM read as `String`, `cut`/`qcut` deprecated. sportsdataverse-py already floors at
  `polars>=2`.
- **Apache Arrow / PyArrow 26.0.0** (2026-10-09): Python 3.15 wheels, DLPack 1.3 tensor
  conversion, new remainder/modulo/search-sorted kernels, float16 hash kernels; drops Python 3.10
  and pandas < 2.0.3, removes code deprecated ≤ 23.0, deprecates Feather in C++/R. sdv-py
  still supports Python 3.10 — pin `pyarrow<26` there or raise the floor.
- **Airflow 3.4.0b1/b2** (Oct 13 / Oct 20 betas; 3.3.2 stable Sep 17).
- **Dagster 1.13.26** (Oct 9). **Prefect 3.9.0** (Oct 21). **DuckDB 2.0.0** dev builds
  nightly (Oct 16–20) — a 2.0 release looks close.

## 4. Implications for SportsDataverse projects (not yet actioned)

1. **sportsdataverse-py + Arrow 26**: Python 3.10 is dropped upstream; decide whether to cap
   `pyarrow` or lift the 3.10 floor before the next release (the CLAUDE.md still lists 3.10–3.14).
2. **Polars 2.0**: confirm the `cut`/`qcut` call sites noted in CLAUDE.md migrate to `bin_*`;
   re-run the suite against 2.0.0 final (lock was on 2.0 pre-releases).
3. **ABS data**: MLB 2026 ABS challenges and KBO's automated zone give two reasons to expose
   challenge outcomes in the Statcast/MLB surface and `baseballr`; check whether Savant search
   exposes a challenge flag.
4. **Dummy RAPM / L-RAPM / pass-blocking APM** map to `ridge_apm.py` in this repo and to
   hoopR stint construction; a dummy-count column experiment is cheap to reproduce.
5. **Markov/WP**: the rugby Markov paper is a compact reference for the `wexp` engines in sdv-py.
6. **LLM analysts**: AI Soccer Analyst's stage-aware design is a template for sdv-docs MCP
   workflows.
