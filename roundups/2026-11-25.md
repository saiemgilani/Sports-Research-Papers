## 1. Sports Analytics Literature & Research

**Two new papers today**, both from the 11-24 submissions and both about video-language models that produce live, timed feedback.

- **[SoccerNarrate: Event-Grounded Streaming Soccer Commentary](https://arxiv.org/abs/2611.32153)** (Jia et al., Nanjing U. MCG, 11-24). **16/30** (N5 P4 R7).
  - **Data:** a time-anchored commentary corpus built from 436 SoccerNet full matches (391 train / 45 test), with word-level ASR alignment, quality filtering and entity calibration.
  - **Method:** a Qwen2.5-VL-7B streaming model, tuned with macro-window preference alignment. Rollouts from the same prefix are compared at the event level, and human commentary of a *different* event serves as the hard negative.
  - **Result:** event F1 over 14 classes (class-averaged / overall) rises from 30.0/35.3 for a fine-tuned StreamingVLM to 46.9/54.4. Offline clip models such as SoccerChat reach similar recall but much lower precision.
  - **Limits:** after context eviction it still makes up background facts, for example a player's season record.
  - **Availability:** code and models on [GitHub](https://github.com/MCG-NJU/SoccerNarrate). The video stays under SoccerNet's NDA.
- **[StreamCoach: Proactive Sports Coaching via Continuous Visual Reasoning](https://arxiv.org/abs/2611.32281)** (Liang et al., 11-24). **15/30** (N6 P4 R5).
  - **Data:** EE4D-Stream, 1,213 Ego-Exo4D sequences (about 15 h of basketball, soccer and bouldering). An LLM turned 34,058 expert commentary recordings into 51,596 time-localised claims. A spot audit found 94.8% polarity agreement and 88.3% of claims grounded within 0.5 s.
  - **Method:** a streaming video-LM reasons step by step and emits an evidence-gated `<speak>` token. Reinforcement learning trains it on both when to speak and what to say.
  - **Result:** it ranks first on all eight metrics against 11 baselines. Speak F1 is 18.4% above MMDuet-7B. Against Claude Opus 5.5 it gains 53.6% on Speak F1 and 121% on LLM-Score, and it doubles Macro-Recall from 0.31 to 0.63. It still trails baselines given the true feedback times on BERTScore.
  - **Limits:** the labels come from an LLM and are only spot-checked, and the paper gives no code link.
- **Judged off-topic:** 2611.33011 (MESSI, physics-based soccer character animation, the same call as for the humanoid-soccer paper 2611.06564), 2611.33039 (betting-based statistical testing), 2611.32965 and 2611.32926 ("hockey-stick" identities in combinatorics).

## 3. Data Engineering & Tooling

- **Polars 2.2.0 (11-24)** ([PyPI](https://pypi.org/project/polars/2.2.0/), [release notes](https://github.com/pola-rs/polars/releases)).
  - **Headline feature:** **out-of-core joins**. This closes the gap left by 2.0, whose streaming default spilled most operations to disk but not joins or group-bys.
  - **Breaking changes:**
    - `Expr.str.find` / `find_many` now return character offsets, and the new `Expr.bin.find` / `find_many` cover byte offsets.
    - Scalar function arguments are required at plan time.
    - SQL `DELETE` now changes the table registered in a `SQLContext`.
  - **SDV impact:** sdv-py pins `polars>=2.0,<3`, so 2.2 is in range. Check any `str.find` call sites that slice by byte offset before re-locking. Polars 2.1+ needs Python ≥3.11, so the 3.10 job stays on 2.0.
- **Prefect 3.9.5 (11-24)** is a stable patch ([PyPI](https://pypi.org/project/prefect/3.9.5/)).
- **Unchanged:**
  - PyArrow 26.0.1, pandas 3.1.1, Dagster 1.13.31, dbt-core 1.12.7, Airflow 3.4.0 and dlt 1.32.0 (1.33.0a3 is still a pre-release).
  - DuckDB 2.0.1: files written by 2.x cannot be read by 1.x, and nightly 2.0.2 dev builds continue.
